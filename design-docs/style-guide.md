Hayda Min Style Guide

Theme: "Warm & Familiar"

Color Palette

Primary Accent

Hex: #5F8575

Name: Sage

Usage: Main buttons, links, highlights

Warm Accent

Hex: #d4a373

Name: Tan

Usage: Photos, illustrations, secondary highlights

Secondary

Hex: #F4F1EE

Name: Light Oat

Usage: Card backgrounds

Background

Hex: #FAF7F5

Name: Oat

Usage: Page background

Text

Hex: #4E4A47

Name: Coffee

Usage: All body text, headlines

Accent Text

Hex: #FAF7F5

Name: Oat

Usage: Text on accent background (e.g., on the main Sage button)

Typography

Primary Font: 'Poppins'

Usage: Used for all English UI elements, labels, and helper text.

Examples:

Heading 1

Heading 2

Heading 3

Body Text (Large): 24px

Body Text (Base): 18px

Secondary Font: 'Tajawal'

Usage: Used for all Arabic content, including names and relationships.

Examples (RTL):

عنوان رئيسي 1

عنوان رئيسي 2

عنوان رئيسي 3

نص المحتوى (كبير): 24px

نص المحتوى (أساسي): 18px

Components

Buttons

Primary Action Button

Description: The main "؟هايدا مين" button.

Styling:

Background: Primary Accent (Sage, #5F8575)

Text: Accent Text (Oat, #FAF7F5)

Font: 'Tajawal', large (e.g., 36px), bold

Shape: Large padding, large rounded corners (e.g., 24px)

Interaction: Subtle shadow and lift on hover/press

Back Button

Description: Circular button with a left-arrow icon.

Styling:

Background: Secondary (Light Oat, #F4F1EE)

Icon Color: Primary Accent (Sage, #5F8575)

Shape: Circle (e.g., 60x60px)

Size: Large touch target with a bold icon

Cards

Info Card

Description: The base card style used for all main content blocks.

Styling:

Background: Secondary (Light Oat, #F4F1EE)

Shape: Large padding (e.g., 32px), large rounded corners (e.g., 24px)

Shadow: Very subtle, soft shadow

Reveal Card

Description: The card that appears after pressing the "؟هايدا مين" button.

Styling:

Background: Background (Oat, #FAF7F5) to contrast with the Info Card it sits on.

Shape: Rounded corners (e.g., 16px)

Text: Centered, with the name in 'Tajawal' (Text color) and the relationship in 'Tajawal' (Primary Accent color).

Family Link Card

Description: Small card used in the horizontal scrolling list to link to family members.

Styling:

Image: Square (1:1 aspect ratio) photo with rounded corners.

Text Block: White background, centered 'Tajawal' text for name and relationship.

Shape: Rounded corners, subtle shadow.
